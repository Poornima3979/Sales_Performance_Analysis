Sales Performance Analysis

Project Overview

This project analyzes sales performance using Microsoft Excel and Power BI.

Tools Used

- Microsoft Excel
- Power BI

Project Objectives

- Analyze total sales and profit
- Identify sales performance trends
- Understand product and category performance
- Create an interactive Power BI dashboard
- Present key business insights using charts and KPIs

Project Files

- Excel Analysis File
- Power BI Dashboard
- Dashboard Report
- Project Presentation
- Original Dataset

Key Outcome

The project provides a clear visual overview of sales performance and helps identify important business trends and insights.
