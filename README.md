A comprehensive data analytics project focused on evaluating sales trends, regional performance, and key revenue metrics using **Excel** and **Power BI**. This project transforms raw data into interactive dashboards to drive data-backed business strategies.

## Project Overview
This repository provides a step-by-step breakdown of sales efficiency, customer segment distributions, and product line growth. The goal is to isolate operational bottlenecks and surface high-value opportunities for revenue optimization.

## 📁 Repository Structure
The repository is structured to separate documentation, raw data resources, and final outputs logically:

*   **`01.Project_Presentation_Report`** - A professional summary document detailing executive insights, methodology, and recommendations.
*   **`02.Power BI Dashboard`** - The interactive workspace file (`.pbix`) housing dynamic visual charts and data models.
*   **`03.Excel_Analysis_File`** - Core workbook detailing data preparation, exploratory calculations, pivot tables, and initial models.
*   **`04.Original_Dataset`** - The foundational, unmodified source datasets used for processing.
*   **`05.Dashboard_Report.pdf`** - A static graphic export of the primary Power BI interface for quick previews.

## 🛠️ Tools & Technologies Used
*   **Microsoft Excel:** Applied for data cleansing, text processing, conditional sorting, and exploratory data analysis (EDA).
*   **Power BI Desktop:** Utilized to write advanced DAX calculations, build target data models, and deploy interactive visualization dashboards.
*   **Markdown:** Formatted repository files and project documentation systematically.

## 📈 Key Insights & Features
*   **Dynamic Visual Filters:** Filter core performance matrices by fiscal periods, sales territories, and product segments.
*   **Trend Identification:** Deep-dive logic pointing out periodic revenue dips and performance anomalies.
*   **KPI Tracking:** Immediate high-level metrics tracking core performance against operational quarterly milestones.

## 🚀 Getting Started
1. Clone or download this project repository locally.
2. Open the source tables in the `03.Excel_Analysis_File` directory to review the underlying structure.
3. Open `02.Power BI Dashboard` locally inside **Power BI Desktop** to interact fully with the live reports.
