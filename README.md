## 🔵 Project Overview

**Sales Performance Analysis** is a beginner-friendly data analytics project created using **Microsoft Excel and Power BI**.

The project analyzes sales, profit, product performance, customer segments, and trends to generate meaningful business insights through an interactive Power BI dashboard.

---

## 🛠️ Tools Used

- 📗 **Microsoft Excel** – Data cleaning, calculations and Pivot Table analysis
- 📊 **Power BI** – Data visualization and interactive dashboard
- 📁 **CSV** – Source dataset

---

## 📊 Power BI Dashboard

The dashboard contains **6 analytical charts and 7 KPI cards** to provide a clear overview of sales and profitability.

### 📈 6 Charts

1. **Sales and Profit Trends Over Time**
2. **Sales by Category**
3. **Sales by Segment**
4. **Sales vs Profit by Category**
5. **Sales and Profit Margin by Category**
6. **Sales by Product**

### 🎯 7 KPI Cards

- 💰 **Total Sales:** ₹320,133.11
- 📈 **Total Profit:** ₹70,726.50
- 📦 **Total Quantity:** 1,523
- 💵 **Average Profit:** ₹141.45
- 🛒 **Total Orders:** 500
- 💳 **Average Order Value:** ₹640.27
- 📊 **Profit Margin:** 22.09%

## 📈 Key Business Analysis

### 🔹 Sales Analysis
Analyzed sales performance across **categories, products and customer segments**.

### 🔹 Profitability Analysis
Compared **sales and profit by category** and calculated the overall **profit margin**.

### 🔹 Trend Analysis
Analyzed **sales and profit trends over time** to understand changes in business performance.

### 🔹 Product Analysis
Evaluated product-level sales performance to identify differences in sales contribution.
